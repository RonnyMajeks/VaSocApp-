1. ====RUN THE PROJECT====
1. Open the "VaSocApp System.sln" file in Visual Studio.
2. Visual Studio will automatically restore the required NuGet packages (including BCrypt.Net-Next and ClosedXML for Excel exports). Wait for this to finish.
3. Press F5 or click the "https" play button at the top to run the application.
4. The application will open in your default web browser.
